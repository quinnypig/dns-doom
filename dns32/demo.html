What is running?

Unmodified DNS software supplies arithmetic truth tables and persistent machine state. Native transport, pipelined queries, packed registers, and compiled instruction blocks reduce overhead. Python supplies the external clock and wires.

Fibonacci executes from its entry point. Doom uses a locally initialized E1M1 snapshot; it advances one game tick and turns right. This is a computation demonstration, not an interactive full game.
