How this works

Doom is compiled for 32-bit RISC-V. Instruction decoding happens offline. At runtime, every arithmetic result and every byte of memory is a DNS record; a small Python program supplies the wiring and the clock. A 32-bit add is four lookups. Stock BIND 9.20 runs in a container with networking disabled. All DNS traffic stays inside it. Cloudflare is not involved in the computation.


An independent local emulator initializes E1M1 and saves a checkpoint with the viewport cleared. Each run loads that checkpoint, holds Right for one game tick, and renders a 96×48 view. The result is checked against the emulator: every pixel, all 32 registers, the program counter, and the checked game-state fields. Zone loading happens before the timer starts. This does not cold-boot Doom. It is not playable.
